# Tela, mockup e captura

Mockup, captura ou link do pedido vale como especificação, salvo se o usuário disser que é só inspiração.

- Guarde o arquivo na pasta da spec.
- Cada estado desenhado vira item do checklist citando o arquivo.
- Textos do mockup são copiados exatamente; desvio: pergunte.
- Toda tela cobre os estados vazio, carregando, erro e sem permissão, e cada controle diz o que acontece quando usado.
